1答案：C (III)

Step-by-step / 讲解步骤

Same-base multiplication: m⁸ × m³ = m⁸⁺³ = m¹¹.

记忆点：同底相乘，指数相加。
2答案：A (3906.25 m²)

Step-by-step / 讲解步骤

Scale is 1:2500 for length, so area scale is 1:2500². Convert the sketch square side first: √6.25=2.5 cm; actual side=2.5×2500=6250 cm=62.5 m; area=62.5²=3906.25 m².

面积题不能直接把6.25乘2500。先由面积找边长2.5 cm，再放大2500倍得62.5 m，最后平方得3906.25 m²。

记忆点：长度比例先处理，面积最后平方。
3答案：D (RM 5925.06)

Step-by-step / 讲解步骤

Compound yearly: A=P(1+r)^n=5500(1.015)^5≈5925.06.

复利就是“利息也会继续生利息”。每年乘1.015，连续5年，得到RM5925.06。

记忆点：复利：本金 × (1+利率)^年数。

5答案：A (20 cm)

Step-by-step / 讲解步骤

Rectangle gives QS=RT=16 cm and QR=ST=8 cm. In right triangle PQS, tan X = opposite/adjacent = QS/PQ =4/3, so 16/PQ=4/3 → PQ=12 cm. Hence PR=PQ+QR=12+8=20 cm.

长方形先送你两条边：QS=16，QR=8。tan X=对边/邻边=16/PQ=4/3，所以PQ=12。最后PR=12+8=20 cm。

记忆点：tan = 对边 ÷ 邻边。

1) Fixed distance from a straight line → two lines parallel to it = Q. 2) Fixed distance 3 cm from point M → circle = R. 3) Equidistant from points M and N → perpendicular bisector = P.

记三个最常考locus：离直线固定距离=两条平行线；离点固定距离=圆；离两点等距=垂直平分线。

记忆点：直线→平行线；点→圆；两点等距→垂直平分线。
